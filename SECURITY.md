# Sicherheit

## Eine Lücke melden

Melde Sicherheitslücken **nicht** über ein öffentliches Issue.

Nutze die Funktion *Security → Report a vulnerability* dieses Repositories oder
das Kontaktformular auf [speedofthespirit.dev](https://speedofthespirit.dev).

Was in die Meldung gehört: was betroffen ist, wie sich das Verhalten auslösen
lässt, und was im schlimmsten Fall daraus folgt. Eine Antwort kommt innerhalb
von 72 Stunden.

## Was hier nicht liegt

In diesem Repository liegen keine Schlüssel, Zugangsdaten, Nutzerdaten oder
Marktdaten. Schlüssel werden zur Laufzeit aus der Umgebung gelesen; Passwörter
werden nie im Klartext gespeichert.

Wer trotzdem etwas findet, das nach einem Schlüssel aussieht: bitte melden, auch
wenn es nur ein Beispielwert aus einem Test ist.

## Unterstützte Fassung

Gepflegt wird der Stand auf `main`. Ältere Stände bekommen keine Nachbesserung.
