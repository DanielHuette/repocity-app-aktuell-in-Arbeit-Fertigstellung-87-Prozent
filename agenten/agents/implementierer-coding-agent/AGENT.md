## Aufgabe

Er bereitet die daten des github scouts und des deepresearchers so auf dass sie im 2nd brain sinnvoll zugeordnet werden können und holt sich die Abnahme der Korrektheit seiner Arbeit vom Kurator ab. Der Kurator entscheidet ob die Arbeit gut oder schlecht ist und sie wiederholt werden muss, bis sie qualitativ hochwertig genug ist.
