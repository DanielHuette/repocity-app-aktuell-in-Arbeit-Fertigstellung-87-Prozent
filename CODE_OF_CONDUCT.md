# Verhaltensregeln

## Worum es geht

Hier wird an einer Sache gearbeitet. Wer mitarbeitet, tut das sachlich und
ohne Herabsetzung — unabhängig von Herkunft, Geschlecht, Alter, Religion,
Behinderung oder Erfahrungsstand.

## Erwünscht

- Zur Sache schreiben, nicht zur Person.
- Kritik begründen. Ein „das ist falsch" ohne Grund hilft niemandem.
- Fehler benennen, auch eigene.
- Fragen stellen, bevor man rät.

## Nicht erwünscht

- Beleidigungen, Herabsetzung, Anspielungen auf die Person.
- Belästigung jeder Art, öffentlich oder in Nachrichten.
- Veröffentlichen fremder personenbezogener Daten.
- Beiträge, die erkennbar nur Aufmerksamkeit suchen.

## Wenn etwas vorfällt

Meldung über das Kontaktformular auf
[speedofthespirit.dev](https://speedofthespirit.dev). Meldungen werden
vertraulich behandelt. Der Betreuer des Projekts entscheidet über die Folge —
von einem Hinweis bis zum Ausschluss.
